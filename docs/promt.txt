# 3. TECHNOLOGY ARCHITECTURE

Use the following architecture where compatibility is verified:

- Frontend: TypeScript, React, and a Cloudflare-compatible full-stack framework.
- Runtime and hosting: Cloudflare Workers.
- Database: Cloudflare D1 with SQL migrations.
- Image storage: Cloudflare R2.
- Real-time events: Durable Objects with WebSockets.
- Validation: a maintained schema-validation library compatible with Workers.
- Styling: plain CSS or CSS Modules.
- Testing: compatible unit and integration testing tools.
- Version control: Git.

Prefer the simplest maintainable architecture. Avoid unnecessary dependencies and microservices.

Do not use Prisma unless its current D1 compatibility, migration workflow, and transaction behavior are explicitly verified. Native D1 prepared statements and SQL migrations are acceptable.

Use Cloudflare bindings for D1 and R2. Never expose storage credentials, session secrets, or private environment variables to the browser.
